TeamHub 사용 매뉴얼

APS Innovation 비전개발팀 업무 대시보드 · 2026년 11월 기준

1시작하기

TeamHub는 팀 일정, 일간·주간보고, 출장 계획, 이슈, 장비(Parts), 회의록, 매뉴얼을 한곳에서 함께 보는 팀 업무 사이트입니다. 입력한 내용은 바로 서버에 저장되고, 팀원 모두에게 같은 내용이 보입니다.

접속 주소

  • 팀 사이트: sites.google.com/view/apsi-vision
  • 단독 화면(새 창): jaeyounglee02.github.io/team-dashboard/Index.html
💡팀 사이트 안에서 로그인 창이 안 뜨거나 엑셀이 안 받아지면, 오른쪽 위 새 창을 눌러 단독 화면으로 여세요. 단독 화면 주소를 즐겨찾기해 두면 편합니다.

로그인과 가입

  1. 사이트를 열면 로그인 화면이 나옵니다. Google 계정으로 로그인을 누릅니다.
  2. 처음 한 번만: 팀원 목록에서 본인 이름을 골라 가입 요청을 보냅니다.
  3. 관리자가 승인하면 바로 사용할 수 있습니다. 승인 후 새로고침하세요.
  • 회사 이메일과 같은 Google 계정으로 로그인하면 승인 없이 바로 들어갑니다.
  • 개인 Gmail 등 다른 Google 계정도 가입 요청 → 승인으로 쓸 수 있습니다.
  • 로그인은 30일 동안 유지됩니다. 오른쪽 위 프로필을 눌러 로그아웃할 수 있습니다.

휴대폰에 설치 (앱처럼 쓰기)

앱스토어 없이 홈 화면에 아이콘을 만들어 앱처럼 씁니다. 반드시 단독 화면 주소로 열어서 설치하세요(팀 사이트 주소로 설치하면 Google Sites가 설치됩니다).

안드로이드 (Chrome)

  1. Chrome으로 단독 화면 주소를 엽니다. 카카오톡에서 열렸다면 ⋮ → 다른 브라우저로 열기.
  2. 오른쪽 위 ⋮ → 앱 설치 (또는 홈 화면에 추가).
  3. 홈 화면의 TeamHub 아이콘으로 열고 로그인합니다.

아이폰 (Safari)

  1. Safari로 단독 화면 주소를 엽니다.
  2. 아래쪽 공유 버튼(네모에 위쪽 화살표) → 홈 화면에 추가 → 추가.
  3. 홈 화면 아이콘으로 열고 로그인합니다.

화면이 바뀌어도 다시 설치할 필요 없이, 다음에 열 때 자동으로 새 화면이 됩니다.

3매일·매주 할 일

✅매일 퇴근 전(18:00) 일간보고 · 매주 목요일 12:00까지 주간보고

일간보고

  1. 일간보고 메뉴 → + 일간보고 작성.
  2. 날짜와 근무지(사내현장재택이동 중)를 고릅니다.
  3. 오늘 한 일을 오전 / 오후로 나눠 적고, 내일 할 일을 적습니다.
  4. 막힌 일이나 도움이 필요한 일은 블로커 / 특이사항에 적습니다. 팀 현황의 블로커·지원 요청에 바로 보입니다.
  5. 저장.
  • 자정이 지나 새벽에 쓰면 날짜가 전날로 자동 선택됩니다.
  • 본인 보고만 고치거나 지울 수 있습니다.
  • 날짜·작성자로 걸러 볼 수 있고, 엑셀로 내보내기로 그날 보고를 한 파일로 받을 수 있습니다.

주간보고

  1. 주간보고 메뉴 → + 주간보고 작성.
  2. 금주 완료 및 진행 사항, 차주 계획, 이슈 및 지원 요청을 적고 저장합니다.
  • 마감은 매주 목요일 12:00입니다(일정에 반복 일정으로 등록되어 있습니다).
  • 주차·작성자로 걸러 보고, 엑셀로 내보내기로 주차별 정리본을 받습니다.
  • 위쪽 주간 보기 / 월간 보기로 바꾸면 한 달 치 주간보고를 사람별로 모은 월간 보고(출장·연차·프로젝트 포함)를 보고, 복사하거나 엑셀로 받을 수 있습니다.
  • 긴 보고는 처음에 일부만 보이고 전체 보기 ▾를 누르면 펼쳐집니다(일간보고도 같음). 접기 ▴로 다시 줄입니다.

글자 서식 넣기 (굵게 · 빨강 · 형광펜 · 목록)

일간보고, 주간보고, 회의록(안건·회의 내용·결정 사항), 공지 본문 입력 칸 위에 서식 버튼이 있습니다.

  1. 꾸미고 싶은 글자를 마우스로 선택합니다. (휴대폰은 길게 눌러 선택)
  2. 입력 칸 위 버튼을 누릅니다.
  3. 저장하면 보고서 화면에 서식이 적용되어 보입니다.

4메뉴별 사용법

팀 현황

들어오면 처음 보이는 화면입니다.

  • 오늘 확인 필요: 마감 임박·지연 프로젝트(7일 이내), 블로커·지원 요청, 긴급·기한 지난 이슈, 오늘 일간보고 미작성자. 해결되면 자동으로 사라집니다.
  • 최근 공지, 오늘 일정, 출장·외근 중인 인원, 다가오는 일정.

공지·News

  • 글쓰기로 공지를 올립니다. 분류: 공지News행사·교육기타
  • 중요한 글은 위에 고정할 수 있습니다. 본인 글만 고치거나 지울 수 있습니다.

일정 관리

  • 달력과 목록으로 팀 일정을 봅니다. 분류: 팀 회의마감일배포/릴리스출장/외근휴가/부재기타
  • 반복을 체크하면 매주·매월 같은 일정이 자동으로 이어집니다.
  • 3일 이상인 출장은 달력 칸에 시작일과 종료일만 표시되고, 오른쪽 목록에는 기간 전체가 보입니다.
  • 연차·반차는 휴가/부재로 등록하세요. 연차 합계가 여기서 계산됩니다(주말·공휴일 제외, 제목에 '반차'가 있으면 0.5일).

회의록

  • + 회의록으로 날짜, 종류(주간 회의고객 회의내부 회의현장 회의기타), 참석자, 내용, 결정 사항, 할 일을 적습니다.
  • 누구나 쓰고 고칠 수 있습니다. 지우기는 작성자와 관리자만 할 수 있습니다.

이슈 트래킹

현장·고객 문제를 접수부터 종료까지 기록합니다. 누구나 등록할 수 있습니다.

  • 등록할 때: 제목, 사이트, 분류(검사 성능(과검·미검)하드웨어(카메라·조명)소프트웨어통신·PLC고객 요청기타), 심각도(긴급높음보통낮음), 담당자, 기한, 내용.
  • 진행 상태: 접수 → 진행 중 → 고객 확인 대기 → 해결 → 종료
  • 이슈를 열어 진행 기록을 계속 덧붙입니다. 여러 사람이 동시에 적어도 기록이 합쳐집니다.
  • 목록 / 칸반 / 사이트별 보기로 바꿀 수 있고, 엑셀로 내보낼 수 있습니다.
  • 긴급 이슈와 기한 지난 이슈는 팀 현황의 '오늘 확인 필요'에 올라옵니다.

프로젝트 관리

  • 프로젝트별 상태(기획/대기진행중검토중완료), 진행률, 마감일, 담당자를 관리합니다.
  • 마감 7일 이내이거나 지연된 프로젝트는 팀 현황에 표시됩니다.

인원 관리

  • 팀원 이름, 직급, 회사 이메일, 현재 상태를 봅니다. 직급 순, 같은 직급은 이름 가나다순입니다.
  • 팀원 카드에 올해 연차 사용 일수가 보이고, 연차 사용 현황에서 전체를 봅니다.
  • 팀원 추가·수정·가입 승인은 관리자가 합니다(관리자 기능 참고).

출장 계획

  • 한 해 출장 계획을 사람 × 월 표(간트)로 봅니다. 색은 사이트별로 다릅니다. 막대에 마우스를 올리면 기간·사이트가 보입니다.
  • 아래에 월별 출장 인원 합계가 자동으로 계산됩니다.
  • 엑셀로 내보내기로 표를 그대로 받습니다.
  • 출장 추가·수정, 사이트 관리, 월별 인력 입력은 관리자가 합니다.

Parts 관리

팀이 가진 장비와 대여품을 관리합니다. 누구나 등록·수정할 수 있습니다.

  • 분류: 카메라, 렌즈, 조명, 조명 컨트롤러, 프레임 그래버·보드, PC·노트북, 케이블·커넥터, 센서·엔코더, 지그·브래킷, 계측 장비, SW 라이선스·동글, 기타
  • 상태: 보관 중사내 사용 중현장 반출수리 중반납 완료폐기
  • 대여품은 반납 기한을 넣으면 기한 지난 항목이 따로 표시됩니다.
  • 품명·모델로 검색하고, 엑셀로 내보낼 수 있습니다.

업무 Pool (매뉴얼/이슈)

  • 매뉴얼, 트러블슈팅, 온보딩 자료, 회의록·정책 문서를 모아 두는 곳입니다.
  • 파일을 올릴 수 있습니다. 줄인 뒤 2MB까지: 사진은 자동으로 압축되고, Word 파일은 웹 문서로 바꿔 저장합니다. 올린 파일은 화면에서 바로 미리 봅니다.
⚠️큰 파일(동영상, 대용량 PDF 등)은 회사 드라이브에 올리고 링크만 붙여 넣으세요.

팀 대화방

  • 왼쪽 아래 보라색 버튼으로 엽니다. 사진을 첨부할 수 있습니다.
  • @이름으로 특정 팀원을 부를 수 있습니다. Enter는 보내기, Shift+Enter는 줄바꿈입니다.

5알림 메일

보고를 쓰지 않으면 회사 이메일로 알림이 옵니다. 출장 중이면 그 사이트의 현지 시각 기준입니다(시간대가 없는 사이트는 미국 오하이오 시각).

보고알림 시각마감
일간보고근무일 17:30퇴근 전 18:00
주간보고목요일 11:00목요일 12:00
  • 주말, 공휴일, 휴가 중에는 보내지 않습니다.
  • 처음 받은 메일이 스팸함에 있으면 '스팸 아님'으로 표시해 주세요.

6관리자 기능 관리자

관리자로 로그인하면 프로필 옆에 관리자 표시가 보이고, 아래 기능을 쓸 수 있습니다.

팀원 관리

  • 가입 승인: 인원 관리 맨 위 '가입 요청' 목록에서 승인 / 거절.
  • 팀원 추가·수정: 이름, 직급, 회사 이메일(알림 메일 받는 주소), 로그인 계정 연결.
  • 제외 옵션: '일간·주간보고 제외'(보고 대상·알림에서 빠짐), '출장 계획 표에서 제외'.
  • 퇴사·전배 시 계정 연결을 해제합니다.

출장 계획

  • + 출장 추가: 사람, 사이트, 기간. 일정 달력에도 같이 표시됩니다.
  • 사이트 관리: 사이트 이름, 색, 시간대(알림 메일 시각과 세계시간에 쓰임).
  • 월별 인력 입력: 자사 셋업 인력, 협력업체 셋업, 국내 잔류 인원 등 월별 숫자.

알림 메일

  • 일간보고 메뉴에서 받을 사람 보기로 대상과 이메일을 확인하고 미작성 알림 메일 켜기.
  • 회사 이메일이 비어 있는 팀원에게는 메일이 가지 않습니다.

백업과 데이터 공유 창

  • 자동 백업: 자동 백업 켜기를 누르면 매일 새벽 3시에 Google Drive 'TeamHub 백업' 폴더로 전체 복사본을 만들고 30일 동안 보관합니다. 지금 백업으로 바로 만들 수도 있습니다.
  • JSON 내보내기: 전체 데이터를 파일 하나로 받습니다.
  • JSON 가져오기 / 붙여넣기로 가져오기: 파일(또는 붙여 넣은 내용)로 서버의 모든 데이터를 바꿉니다. 회사 보안 때문에 파일이 안 올라가면 메모장으로 열어 내용을 붙여 넣으세요.
⚠️가져오기와 '초기 샘플 데이터로 되돌리기'는 지금 데이터를 모두 덮어씁니다. 하기 전에 꼭 JSON 내보내기로 받아 두세요.

관리자 추가

Apps Script → 프로젝트 설정 → 스크립트 속성의 ADMIN_EMAILS에 관리자 Google 계정을 쉼표로 이어 적습니다.

7자주 묻는 질문

로그인 버튼을 눌러도 아무 일이 없어요 / 다시 로그인 화면으로 돌아와요

팀 사이트 안에서는 브라우저가 로그인 정보를 막는 경우가 있습니다. 새 창에서 열기를 눌러 단독 화면에서 로그인하세요.

'가입 요청 대기' 라고 나와요

관리자가 아직 승인하지 않았습니다. 관리자에게 승인을 부탁한 뒤 새로고침하세요.

엑셀 내보내기를 눌렀는데 파일이 안 받아져요

팀 사이트 안에서는 내려받기가 막힐 수 있습니다. 오른쪽 위 새 창에서 다시 눌러 주세요.

다른 사람이 입력한 내용이 안 보여요

새로고침하세요. 왼쪽 아래 저장 상태가 Sheets 동기화됨인지 확인하고, 오류가 표시되면 관리자에게 알려 주세요.

보고를 잘못 썼어요

본인 보고는 열어서 고치거나 지울 수 있습니다. 다른 사람의 보고는 고칠 수 없습니다.

연차를 썼는데 연차 합계에 안 잡혀요

일정 관리에서 분류를 휴가/부재로 등록했는지 확인하세요. 반차는 제목에 '반차'를 넣으면 0.5일로 계산됩니다.

파일이 너무 크다고 나와요

업무 Pool은 줄인 뒤 2MB까지 올릴 수 있습니다. 큰 파일은 회사 드라이브에 올리고 링크를 붙여 넣으세요.

휴대폰 앱이 예전 화면이에요

앱을 완전히 닫았다가 다시 열어 주세요. 인터넷이 연결되어 있으면 새 화면을 받아 옵니다.
